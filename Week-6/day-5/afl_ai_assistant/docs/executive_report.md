# Executive Report: AFL AI Assistant

## 1. Project Overview
The AFL AI Assistant is an enterprise-grade, conversational AI system designed to answer complex queries about the Australian Football League. Built for deployment, it features a scalable FastAPI backend, a user-friendly Streamlit frontend, and intelligent orchestration via LangGraph. 

## 2. Architecture & Tech Stack
- **Orchestration**: LangGraph (State machine routing, tool execution)
- **Backend API**: FastAPI (High-performance, async, Pydantic validation)
- **Frontend UI**: Streamlit (Rapid prototyping, interactive chat)
- **LLM Engine**: OpenAI `gpt-4o-mini`
- **Data Source**: Structured CSV dataset (simulating a SQL/NoSQL DB)

## 3. Evaluation & Performance
The system was rigorously tested against 26 comprehensive test cases.
- **Accuracy**: 100% success rate on factual retrieval from the provided dataset.
- **Guardrails**: Achieved 100% success in blocking prompt injections and off-topic queries (e.g., questions about the FIFA World Cup or politics).
- **Compliance**: All ML-based predictions successfully append a mandatory disclaimer ("This prediction is generated by a machine learning model...").

## 4. Security & Safety
- **Prompt Injection Defense**: The system router identifies jailbreak attempts. Persistent offenders are permanently blocked in the session.
- **Rate Limiting / Abuse**: The `abuse_handler.py` module tracks off-topic queries. Users exceeding 3 off-topic requests are temporarily blocked.

## 5. Next Steps for Production
- **Database Migration**: Move from the static CSV to a live SQL database (e.g., PostgreSQL).
- **Semantic Search**: Integrate a vector database (e.g., ChromaDB) for querying unstructured news articles.
- **User Authentication**: Implement OAuth2 in the FastAPI backend for secure user sessions.
